# Tier 3 남은 15건 — 1차 검토 (반영 전)

> 박민재 결정 받은 후 일괄 반영. 현재 시트 컨텍스트는 박민재님이 직접 추가하신 항목들도 일부 반영 (use_planchg, use_addmgmt, exp_offline, ord_offline 등).

## 카테고리 1 — 신규 L2/L3 신설 (5건)

### ① REQ_014 (유수빈) — 결합 관리 L2 신설 (서비스 이용)
- **요청**: "회선 사용 중 타회선과의 결합 신청 여정"
- **현재**: 결합 관련은 `ord_combo`(구매-신규), `exp_family`(유지-가족결합 신청/관리)에 있음. 서비스 이용 단계에 결합 관리 없음
- **1차 검토 의견**: ⚠️ 조건부 — exp_family가 이미 가족결합 신청/관리이고 의미가 겹침
- **권장안**: `exp_family`를 **확장**해서 "가족결합 + 결합 관리" 통합 (별도 L2 신설보다 효율)
  - 또는 옵션 B: 서비스 이용에 `use_combo | 결합 관리` 신설 (회선 사용 중 결합 신청)
- **결정 포인트**: 옵션 A(exp_family 확장) / 옵션 B(use_combo 신설) / 옵션 C(둘 다 유지)

### ② REQ_020 (유수빈) — Care/Marketing 캠페인 접촉 L2 신설 (인입)
- **요청**: "IB/OB 캠페인 접촉 이력도 CJM 여정에 포함"
- **현재 인입 L2**: ent_need, ent_app, ent_store, ent_push, ent_call, ent_chat, ent_ext (7개)
- **1차 검토 의견**: ✅ 수용 — OB 마케팅 분석에 필수
- **권장 신설**: `ent_camp | Care/Marketing 캠페인 접촉`
  - 위치: ent_push 다음
  - L3 후보 (3개): `ent_camp_ob` OB 캠페인(콜·SMS·MMS·메일) / `ent_camp_ib` IB 응대(캠페인 응답) / `ent_camp_event` 이벤트/프로모션
- **결정 포인트**: L3 구성 OK? 또는 단일 L3?

### ③ REQ_034 + REQ_035 (김하연) — T ID / 온라인 채널 회원가입 L2 신설
- **요청**: "회선 개통과 온라인 채널 가입은 별개"
- **현재**: 구매/가입/개통 L2 9개 모두 회선/상품 가입. 비회선 회원가입 없음
- **1차 검토 의견**: ✅ 수용 — 비회선 사용자도 T멤버십/T우주 단독 가입 가능
- **권장 신설**: `ord_member | T ID / 온라인 채널 회원가입`
  - 위치: ord_phone 앞 (가장 먼저)
  - L3 후보 (3개): `ord_member_id` T ID 가입 / `ord_member_app` 앱별 회원가입(T멤버십·T우주 단독) / `ord_member_terms` 약관 동의·인증
- **결정 포인트**: 신설 OK? L3 구성?

### ④ REQ_041 (김하연) — 선택약정 가입/재가입
- **요청**: "선택약정 가입/재가입" L2 (구매/가입/개통에 요청됨)
- **현재**: use_planchg(요금제 변경 관리, use_info 산하)에 약정 관련 L4 일부 있음. exp_devchg(기변)에 약정 정보 일부.
- **1차 검토 의견**: ⚠️ 조건부 — L2 신설보다는 L3로
  - 신규 가입 시 = 회선 가입 일부 (이미 있음)
  - **재가입(약정 만료 후 재선택)** 이 핵심 → 별도 L3가 적절
- **권장 위치**: `use_info` 산하 L3 신설 `use_info_sa | 선택약정 가입/재가입`
  - L4 후보: 약정 만료 알림, 약정 조건 비교, 선택약정 가입, 만료 후 재가입
- **결정 포인트**: L2 vs L3 / 위치 (use_info vs 별도)

### ⑤ REQ_042 (김하연) — 인터넷 주소 이전 / 망 작업 SMS 알림
- **요청**: "자잘해서 넣어야 할지 고민" (2개 기능)
- **현재**: exp_net L2 있음 (인터넷/B tv 확장 - 가입/설치만), ent_push_msg (MMS/RCS 알림) 있음
- **1차 검토 의견**: ✅ 수용 (현장 기능이라 분석 가치 있음)
- **권장 분리 반영**:
  - **주소 이전**: exp_net 산하 L3 신설 `exp_net_relocate | 인터넷/B tv 주소 이전`
    - L4: 이전 신청, 설치 일정 예약, 이전 완료 안내
  - **망 작업 SMS**: ent_push_msg 산하 L4 추가 `ent_push_msg_03 | 망 작업/장애 알림 (인터넷·전화·IPTV)`
- **결정 포인트**: 둘 다 반영 / 일부만 반영 / 보류

## 카테고리 2 — 모델·정책 결정 (6건)

### ⑥ REQ_002 (강희정) — 장바구니 위치 변경
- **요청**: "장바구니는 구매 단계 전환 트리거. 탐색 마지막으로 이동 어떤가요?"
- **현재**: `ord_phone_cart` L3가 ord_phone(구매) 산하 + exp_devchg(기변)에도 동일
- **1차 검토 의견**: ⚠️ 조건부
  - 장바구니는 **두 맥락**: (a) 탐색 종료 트리거 (b) 구매 진입 직전
  - 둘 다 의미 있음
- **권장**: 두 곳에 모두 두기 — 탐색 마지막에 `expl_cart | 장바구니` L2 또는 L3 신설 + 기존 ord_phone_cart 유지 (각각 분석 목적 다름)
- **결정 포인트**: (a) 이동만 / (b) 탐색에도 신설 / (c) 그대로

### ⑦ REQ_018 (유수빈) — 자동 가입 상품 태깅 모델
- **요청**: "QoS제한, 휴대폰결제 동의 등 자동가입 상품에 '자동가입/시스템처리' 태깅 또는 별도 구분"
- **검토**: 현재 use_addmgmt_04 "자동가입/해지 상품 안내"가 있어 부분 대응됨. 그러나 다른 L4에는 자동/수동 구분 없음
- **1차 검토 의견**: ⚠️ 조건부 — 모델 확장 결정 필요
- **권장 옵션**:
  - A. L4 명칭에 "(자동)" 표기 (가벼움, 변경 없음)
  - B. 시트에 신규 컬럼 추가 (예: I열 `발생주체` = 고객/자동) — 큰 변경
  - C. channels 컬럼처럼 별도 분류 컬럼
- **결정 포인트**: A / B / C / 보류

### ⑧ REQ_046 (유수빈) — CS 상담 상태 분리 모델
- **요청**: "상담 인입·처리중·완료 분리. 미결 건 누수 방지, 미결 고객 OB 마케팅 지양"
- **현재**: use_cs_offline 산하 L4 7개 (요금/납부/신고/명의변경/상품변경/불만/콜백)
- **1차 검토 의견**: ⚠️ 조건부 — 모델 차원 결정
- **권장 옵션** (REQ_018·051과 묶음):
  - A. L4를 상태별로 더 세분화 (각 7개 → 7×3=21개)

## 박민재님 직접 추가하신 항목 (참고)

시트 구조 dump 중 확인된 박민재님 직접 작업 (변경이력에 없는 것들):
- `ord_offline` L2 (구매/가입/개통, 대리점/고객센터 통합 개통)
- `exp_offline` L2 (유지/확장, 변경 관리)
- `use_planchg` L3 (use_info, 요금제 변경 관리) — REQ_040 일부 해결됨
- `use_addmgmt` L3 (use_info, 부가서비스 관리)
- `use_info_*` 다수 L3 (회원정보, 회선 관리, 번호변경, 명의변경 등)
- `ord_resv`가 탐색 위치 (row 96, 우리가 만든 건 구매/가입/개통 → 이동된 듯)

이 항목들은 변경이력 미기록 상태. 정합성을 위해 변경이력에 후처리 추가가 필요할 수 있음.
