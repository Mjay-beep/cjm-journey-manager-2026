## ③ 메일 의견 4건

### A. 김하연 (T서비스기획) — KPI 신규 제안 3건
| KPI | L1 | 산식 |
|---|---|---|
| self 업무 처리 완료율 | 탐색 | 업무 처리 완료 세션 수 ÷ 업무 처리 메뉴 진입 세션 수 |
| 약정 만료 후 재약정 전환율 | 서비스 이용 (나의 가입정보) | 만료 +30일 내 재약정 / 해당 월 약정 만료 고객 |
| 위약금 조회 후 해지 전환율 (역방향) | 서비스 이용 (나의 가입정보) | 조회 +30일 내 해지 / 위약금 조회 고객 |

### B. 문정연 (MNO AX Initiative) — CJM 구조 보완 의견
- **인입**: 단골문자 MMS 알림 추가 ｜ 광고(채널)·이벤트(컨텐츠) MECE 구분 필요 ｜ 생애주기별 트리거 보완 (결혼→결합)
- **탐색**: 멤버십/혜택 탐색에 프로모션 조회 포함 ｜ 개인화 추천에 이벤트/프로모션 포함
- **구매·가입·개통**: 마케팅프로그램 가입(이벤트 응모하기 등) 신설
- **유지 및 확장**: 요금제 변경/관리 L3 추가 ｜ 장기고객 혜택 이용을 탐색→유지로 이관
- **이탈**: 해지고객 데이터 보관 동의 프로세스 추가

### C. 원용준 (로밍팀, MNO AX 파견) — KPI 4건 + 측정 가능성 문의
- **추가 KPI**: 탐색→가입 전환율, 로밍 가입 완료율
- **측정 가능성 문의 4가지**:
  1. 광고/외부배너/앱푸시 등 비정형 인입 채널 전부 트래킹 가능한가
  2. 온라인 외 채널(로밍부스·고객센터·MTR·콜봇·챗봇) 가입 전환율 측정 가능한가
  3. 출국 데이터 기반 이탈 판단 가능 여부
  4. baro 요금제 upsell 팝업 이후 상위 전환율, 채널별 전환율, 재인입 가입 비율, 데모(연령/첫로밍)별 통계 가능 여부
- **요청**: 후속 인터뷰는 로밍팀 실무자(민채님) 동석 권장

### D. 유통망 관리팀 — 작성 가능 범위 + 구조 제안
- **자평**: 본 팀 업무(유통망 비용·계약·정산·영업품질)는 고객 여정과 scope 차이 → KPI 직접 작성은 비전문적. **마케팅전략팀 / SALES MARKETING혁신팀** 검토 권장
- **구조 제안**: 대리점/고객센터 변경관리·가입관리가 L2에 누락. 기기변경 등 L2 하단에 `[대리점/고객센터]` 분기 추가 필요
- **근거**: 대리점 실제 업무 흐름 = 조회 → 변경 → 가입 → 해지 (SWING에서 확인 가능)
