# NOVA SBF KPI — 채택/제외 사유 상세

## 전체 정리 기준

NOVA SBF KPI는 SK텔레콤 **임직원 D2 업무별 KPI** (총 109건). 우리 고객 여정 KPI 시트와는 측정 관점이 다름:

| 관점 | NOVA SBF | 우리 KPI Manager |
|---|---|---|
| 측정 주체 | **임직원 업무 효율** (예: 직원 1인당 처리량, 시스템 비용) | **고객 행동·여정** (예: 전환율, NPS) |
| 1차 사용자 | 사업·운영팀 | CX·마케팅·서비스기획 |

→ NOVA SBF 중 **"고객이 행동한 결과를 측정하는 KPI"** 만 채택 (= 고객 여정에 직접 매핑 가능). 임직원 효율·비용 KPI는 제외.

## 채택 원칙 (4가지)

| # | 원칙 | 예시 |
|---|---|---|
| 1 | **고객 행동·반응 측정** = 채택 | 신규 유치 CTR (고객이 광고에 반응) |
| 2 | **고객 전환·완료 측정** = 채택 | 신규 유치 CVR, 개통 성공율 |
| 3 | **고객 만족도·체감 가치** = 채택 | NPS, 가입 혜택 체감 가치 |
| 4 | **임직원 업무 효율 / 시스템 비용** = 제외 | 기획 리드타임, 고객당 IT 운영 비용 |

## A. 채택 38건 — 채택 사유

### A-1. 인입 (9건)
| KPI | 채택 사유 |
|---|---|
| 채널별 획득 비용 편차 | 채널 효율성 측정 — 우리 인입 L1의 'CAC' 보완 지표 |
| 고관여 타겟 유입 비율 | 인입 단계 타겟 적중도 — 마케팅 전략 효과 |
| 신규 유치 반응률 (CTR) | 광고·캠페인 노출 후 고객 반응 — 인입 단계 핵심 funnel |
| 고객 오퍼 도달률·노출률 | 타겟 고객에게 얼마나 도달했는지 — 도달 효율 |
| 고객 오퍼 반응률 | 오퍼 본 고객 중 클릭한 비율 — funnel 다음 단계 |
| 유입 funnel 평균 리드타임 | 최초 접촉~개통까지 소요일 — 인입 전체 효율성 |
| 유입 단계별 이탈률 | funnel 각 단계 이탈 분석 — 어디서 빠지는지 추적 |
| 맞춤 오퍼 전환율 | 1:1 오퍼의 가입 전환 — 개인화 마케팅 효과 |
| 첫 오퍼 적합도 점수 | 행동 기반 오퍼 적합도 — 개인화 추천의 품질 |

### A-2. 탐색 (4건)
| KPI | 채택 사유 |
|---|---|
| 랜딩/상품상세 진입율 | 광고 노출 후 실제 진입한 비율 — 인입→탐색 전환 |
| 상품/서비스 탐색 완료율 | 탐색 시작 후 끝까지 본 비율 — 탐색 깊이 |
| 요금제/단말 비교·시뮬레이션 완료율 | 시뮬레이션 사용 후 완료한 비율 — 가입 전 의사결정 효과 |
| 개인화 오퍼 적중률 | 개인화 오퍼 수락 비율 — 추천 품질 |

### A-3. 구매/가입/개통 (5건)
| KPI | 채택 사유 |
|---|---|
| 신규 유치 전환률 (CVR) | 캠페인 반응 → 가입 완료까지 — 핵심 conversion 지표 |
| 개통 성공율 | 주문 후 개통까지 성공한 비율 — 가입 funnel의 마지막 단계 |
| 신규/재약정 할인 적용률 | 할인 혜택 적용 비율 — 가입 의사결정 영향 측정 |
| 가입 후 30일 NPS | 가입 직후 만족도 — 초기 만족도 측정 |
| 부가서비스 Attach Rate | 회선 가입 시 부가서비스 동반 가입율 — ARPU 증대 효과 |

### A-4. 서비스 이용 (11건)
| KPI | 채택 사유 |
|---|---|
| 고객 서비스 만족도 (NPS) | 전체 서비스 만족도 — L1 차원 핵심 KPI |
| 옴니채널 고객 만족도 | 모든 채널 통합 만족도 — 채널 통합 경험 |
| 서비스 이용률 (통화·데이터·콘텐츠) | 가입자가 실제 서비스를 사용하는 비율 — 활성도 |
| 고객당 포인트/쿠폰/캐시백 적용액 | 멤버십 혜택 실제 받는 금액 — 혜택 가치 측정 |

| 상담 품질 만족도 | 상담 후 만족도 — CS 만족도 |
| SOP 위반 상담 관련 불만 인입 건수 | 잘못된 상담으로 인한 불만 — CS 품질 |
| 고객당 유효 인게이지먼트 빈도 | 마케팅 메시지에 반응하는 빈도 — 충성도 |
| 고객 피로도 | 메시지 부담감 — 과도한 마케팅 자제 지표 |
| 중·고가 요금제 비중 | 가입자 중 고가 요금제 비율 — ARPU 구조 |

### A-6. 이탈 (3건)
| KPI | 채택 사유 |
|---|---|
| 맞춤 오퍼 반응률 (기존 고객) | 해지 의향 고객 대상 오퍼 반응 — 리텐션 성과 |

## B. 제외 24건 — 제외 사유

### B-1. 마케팅·운영 **비용** KPI (5건)
원가·비용 관점이라 고객 여정과 거리 멈. 사업 관리 KPI.
- 신규 획득 고객당 지원금/유통망 인센티브
- 고객당 단말 지원금/보조금
- 고객당 멤버십 및 혜택 비용
- 고객당 커뮤니케이션 발송비
- 고객당 채널 운영비
- 고객당 미납 관리비
- 고객 응대 처리 비용 효율

### B-2. 임직원 **업무 효율** KPI (6건)
직원의 일하는 속도·자동화 정도. 고객은 못 느낌.
- 기획/개발 리드타임
- 기획/개발 업무 수작업 처리 비율
- 시나리오/콘텐츠 재사용률
- 메시지/오퍼 실행 품질
- 채널 간 메시지 충돌/중복 발생률
- 후처리 자동화율
- 후처리 누락률

### B-3. **시스템·IT 운영** KPI (3건)
인프라 가동 상태. 고객 행동과 무관.
- 출시 후 초기 장애/버그 발생률
- 고객당 IT 운영 비용
- 시스템 가동률 (Uptime)

### B-4. **분석 모델 성능** KPI (3건)
데이터 모델의 정확도. 임직원 모델링 평가 지표.
- 세그먼트 예측 정확도
- 이탈 예측 정확도
- AICC 전환/처리완료율 (이미 채택한 'AICC 자동 처리 비율'과 중복)

### B-5. **마케팅 운영 커버리지** KPI (1건, 애매)
- **CVM 대상 고객 세그 커버리지** ← 박민재 질문 답변 ↓

## CVM 대상 고객 세그 커버리지 — 자세히

### 정의
- **CVM** = Customer Value Management (고객 가치 관리)
- 산식: `CVM 관리 세그먼트에 포함된 고객 수 ÷ 전체 고객 수`
- 의미: "우리가 마케팅 활동(타겟팅·캠페인 등)으로 적극 관리하고 있는 고객이 전체 중 얼마인가"

### 왜 애매한가?
- **임직원 관점**: 마케팅팀이 얼마나 많은 고객을 관리·타겟팅하는지 = 마케팅 운영 KPI
- **고객 관점**: 고객 입장에서 보면 "마케팅 도달의 깊이" — 인입·탐색 단계에서 받는 마케팅 메시지의 양과 관련

### 채택 vs 제외 판단
- **제외 권장**: 본질적으로 임직원의 운영 활동을 평가하는 지표. 고객의 행동을 측정하지 않음.
- **채택 가능**: "도달 광범위성"이라는 인입 단계 보조 지표로 볼 수도 있음.

### 박민재 결정 옵션
- (제외) — 기존 권장안 그대로
- (채택) — 인입 L1 차원 KPI로 매핑 (출처 = NOVA SBF KPI)
