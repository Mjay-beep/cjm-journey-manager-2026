# KPI Phase 5 — 기존 71건 + Global 표준 KPI 통합 검토

> 박민재 임의 71건도 사실상 AI 생성이라 Phase 5에서 함께 재검토. 결과적으로 글로벌 표준 KPI와 매핑되는 것 다수 → 출처를 "General KPI (AI작성)"으로 변경 권장.

## 0. 분석 결과 한눈에 보기

| 분류 | 건수 | 처리 권장 |
|---|---|---|
| (a) 기존 = Global 매칭 (출처 변경) | **약 56건** | "기존(박민재 임의)" → "General KPI (AI작성)" |
| (b) 기존만 (Global에 거의 없음 — 통신사 특화) | 약 10건 | 그대로 유지, 출처는 "General KPI (AI작성)"로 통일 |
| (c) 빈 KPI 행 (L2만 있고 KPI 없음) | 5건 | 그대로 두기 (Phase 1 빈 L2 행과 같이) |
| (d) Global만 (기존·NOVA에 없음, 신규 추가) | **약 8~12건** | 박민재 결정 후 신규 추가 |
| (e) 자체 중복 | 1건 | 통합 |

→ 결론: **사실상 71건 전부 "General KPI (AI작성)"로 출처 변경 + 빠진 8~12건 신규 추가**

## 2. Global 표준 KPI 중 빠진 것 (신규 추가 후보)

### 글로벌 통신사 표준 KPI 프레임워크 기준 - 빠진 항목 12건

| # | KPI 명 | 매핑 L1 / L2 | 정의·근거 |
|---|---|---|---|
| 1 | **DAU / MAU / Stickiness** | 인입 / (T4S) 공식 앱·사이트 인입 | 활성도 — 이미 NOVA에 있음. **중복 확인 필요** |
| 2 | **App Install Rate** | 인입 / 외부 채널 인입 | 외부 광고 → 앱 설치 |
| 3 | **Pages per Session** | 탐색 (L1 차원) | 탐색 깊이 — Bounce Rate와 보완적 |
| 4 | **Customer Effort Score (CES)** | 서비스 이용 (L1 차원) | "쉽게 이용했는가" — 글로벌 트렌드 (CSAT·NPS 보완) |
| 5 | **Customer Health Score** | 서비스 이용 (L1 차원) | 행동 기반 종합 건강도 (이탈 예측) |
| 6 | **First Bill Shock Rate** | 서비스 이용 / 요금/납부 관리 | 첫 청구서 충격 비율 (가입 직후 해지 트리거) |
| 7 | **Tenure (평균 가입 기간)** | 유지 및 확장 (L1 차원) | 평균 가입 유지 기간 — Retention 보완 |
| 8 | **Voluntary vs Involuntary Churn 비율** | 이탈 (L1 차원) | 자발 vs 비자발 해지 분리 (해지 사유 분석 보완) |
| 9 | **Number Portability Out (MNP Out)** | 이탈 / 회선 해지 | 번호이동 출 비율 — 타사 전환 측정 |
| 10 | **Onboarding Completion Rate** | 구매·가입·개통 (L1 차원) | 가입 후 핵심 활성화 단계 완료 비율 |
| 11 | **Service Activation Time** | 구매 / USIM·eSIM 개통 | 주문 → 활성화까지 평균 시간 |
| 12 | **Promoter Migration Rate** | 서비스 이용 (L1 차원) | NPS 추천자(9-10) 유지 비율 |

> 12건 중 #1 (DAU/MAU)는 NOVA에 이미 있음 — 중복 확인 필요. 나머지 11건이 진짜 신규 후보.
